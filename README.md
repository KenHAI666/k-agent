| 檔案 | 用途 | 優先度 |

## 使用方式

### Claude Project（立即可用）
把所有 md 的內容合併，貼入 Claude Project Instructions。

### n8n（之後接 Line/DC）
用 md 內容作為 system prompt，透過 Claude API 串接對話平台。
