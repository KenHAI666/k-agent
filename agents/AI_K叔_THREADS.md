## Threads 文案格式

**字數：** 150–350 字（最佳互動區間）

**三種文案類型（對應 AGENTS.md 的 3-2-1 比例）：**
```
廢文型   → 日常吐槽、生活觀察（人設文）
知識型   → 實用乾貨、框架觀點（價值文）
故事型   → 個人案例、轉折情節（信任文）
```

**文案結構：**
```
第 1 句：Hook（停止滑動）
第 2-3 句：展開或對比
中間段：核心觀點 or 案例（必須帶 K叔真實經驗）
最後 1-2 句：收尾 + CTA（參考 TOOLS.md 工具五）
```

**Hook 優先序：**
1. 資訊缺口型 — 「為什麼我寫了三個月都沒人看？原來是...」
2. 數字衝擊型 — 「我花了 6 個月才搞懂，但其實只要 3 步驟」
3. 打破預期型 — 「大家都說要先累積流量，我覺得這是錯的」
4. 共鳴提問型 — 「你有沒有那種感覺，每天更新但沒有任何感覺？」

## 演算法紅線（R1-R12）

掃描每篇貼文，任一觸發需提示修改（核心版已在 RULES.md，這裡是完整版）：

| 編號 | 名稱 | 觸發條件 |
|------|------|----------|
| R1 | 互動誘導 | 留言 YES / 點讚選邊站 / tag 朋友 |
| R2 | 標題黨 | 開頭承諾的內容正文沒有兌現 |
| R3 | 首尾不符 | 開頭說 A，文章核心是 B |
| R4 | 內容農場 | 明顯湊字、低資訊密度 |
| R5 | 連續同角度 | 近三篇同主題同切入點 |
| R6 | 低質外鏈 | 指向低可信度或 404 頁面 |
| R7 | 敏感煽情 | 用聳動方式框架敏感話題 |
| R8 | 不感興趣 | 明顯對非目標受眾推送 |
| R9 | 主題混亂 | 一篇文有三個以上主線 |
| R10 | AI 未注入 | 純 AI 語氣，沒有個人故事或場景 |
| R11 | 圖文不符 | 圖片跟文字訴說不同事 |
| R12 | 軟降權累積 | 近期多篇觸碰 R1-R11 |

## 心理框架（/draft 和 /analyze 時使用）

```
Peak-End Rule    → 記憶由「最高點 + 結尾」決定
Zeigarnik 效應   → 未完成的懸念讓人繼續讀
資訊缺口理論     → 中等熟悉度的主題鉤子最強
STEPPS 框架      → 社交貨幣、高喚醒情緒、實用價值最易分享
Hook/Payoff Gap  → 強鉤子配弱內容 = 最傷信任
```

**分享動機分類：**
```
DM 轉傳  → 「這個說出我心聲了」
公開分享 → 「轉這個讓別人知道我懂這個」
身份認同 → 「這個代表我是什麼樣的人」
實用存檔 → 「以後會用到，先存起來」
```
