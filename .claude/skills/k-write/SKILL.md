# K叔寫作流程

2027 Threads 文案寫作課｜AI 協作低摩擦文案。四個步驟對應四堂課。每一步的**查表與範例放在 references/**，用到哪一步才讀那一個檔，不用一次全讀。

| 步驟 | 對應 | 產出 | 細節檔 |
|---|---|---|---|
| 1 寫作摘要 | 第 1 堂 | TA 六格、一頁寫作摘要 | `references/step1-brief.md` |
| 2 文案拆解 | 第 2 堂 | Hook＋內容＋CTA 結構表、拆解報告 | `references/step2-structure.md` |
| 3 AI 協助產出 | 第 3 堂 | 風格卡、素材盤點、3 個開頭、2 版初稿、取捨清單 | `references/step3-draft.md` |
| 4 PDCA 優化 | 第 4 堂 | 改善目標、檢查報告、交稿自查 10 項、下一輪計畫 | `references/step4-pdca.md` |

## 路由：使用者這樣說，就做什麼

先判斷使用者落在哪一步，從那一步開始，不用每次從頭跑。

| 使用者這樣說 | 進哪一步 | 先讀 |
|---|---|---|
| 「要寫一篇…」「這篇寫給誰」「TA 分析」「定目標」 | 步驟 1 | step1-brief.md |
| 「排結構」「大綱」「拆這篇」「給我 Hook」「CTA 怎麼寫」 | 步驟 2 | step2-structure.md |
| 「幫我寫初稿」「寫成我的口氣」「建風格卡」 | 步驟 3 | step3-draft.md |
| 「幫我檢查」「交稿前檢查」「改稿」「為什麼沒人看」「AI 味」「復盤」 | 步驟 4 | step4-pdca.md |
| 「整套」「從頭寫」 | 1→4 依序 | 每步各自的檔 |

**補缺規則：** 從哪一步開始，前面步驟的產出缺了，先補**最少必要欄位**（讀者情境、素材、主要任務、指定度、核心主張），補不齊就標【假設】繼續，不要卡住。整套跑時，每一步結束**停下來讓作者確認**再往下。

**分工：** AI 整理材料、提出選項與初稿、指出問題；**作者決定讀者、主張、取捨與定稿**。這條分工貫穿四步——凡是「只有作者知道」的（真實經歷、像不像自己、要不要這樣賣），AI 標出來請作者確認，不替他決定。

## 共用規則（四步都適用，每次都要守）

### 硬規則（安全核心，不可違反）

- **不編造**數據、客戶、第一人稱經歷、成效、讀者原話。缺的標【需補：＿＿】
- **不把確定程度改大**：「還在嘗試」不能寫成「已經證實」
- 分清楚**事實**（能核對）／**觀察**（特定範圍看到的）／**推論**（可能的解釋）／**假設**（待確認）
- 示範情境要寫明「示範」，不能寫成作者實績
- **作者的人設優先**：學員不寫成 K叔；K叔風格卡只在作者是 K叔時用
- **自然停點可以沒有 CTA**；服務說明文要說清楚方案與下一步；有下一步時只放一個

這些規則的理由：這個 Skill 的價值是幫作者寫出「讀者會信、而且真的是他」的文案。一旦編了數據或把別人的經歷寫成自己的，短期看起來更漂亮，長期毀掉的是信任——那正是變現的根。所以寧可標【需補】留白，也不要補一個好看的假的。

### 避開 AI 句型

「不是 X，是 Y」對仗、連續格言、哲學式收尾、結尾同時塞結論＋建議＋CTA、書面連接詞（然而、值得注意的是、換言之）。完整 AI 味檢測表在 step4-pdca.md。

### 問句收尾與留言 CTA（R1）

- 開放式問題「你也會這樣嗎？」沒有風險，可以用
- 「留言告訴我」「留言『要』領資源」這類**要求留言或特定文字**會影響觸及，但可以用：任務是「行動」（領資源、導流）時，用觸及換名單是作者可以做的取捨，**只提醒代價、不當錯誤**；不要每篇都用
- 「按讚如果你同意」「分享給朋友」「Tag 一個人」不建議用

### 判斷標準（三組，怎麼用看下表）

| 標準 | 元素 | 怎麼用 |
|---|---|---|
| 內容三件事 | 生活／經歷／專業 | 素材來源，必須是作者真的有的 |
| 內容三度 | 辨識度／專業度／價值度 | 依主要目的**指定一度**，發前只檢查這一度；任何文類都可選任何一度 |
| 信任三角 | 熟悉感／親切感／價值感 | 長期觀察用；不打分數，也不當發文配額 |

| 指定的度 | 發前檢查 | 讀者感受 |
|---|---|---|
| 辨識度 | 有沒有作者的選擇或經驗，遮掉名字也認得出 | 我記得你 |
| 專業度 | 有沒有說清楚判斷理由、方法或適用條件 | 我覺得你懂 |
| 價值度 | 讀者讀完能多做哪個判斷，或完成哪一步 | 我覺得有用 |

### 其他

- 字數以 50–200 字作練習參考，依任務調整
- 帳號定位、商品 A→B、引流、PDCA 的完整版在〈Threads 低摩擦經營〉，兩門課互補；這裡處理單篇
- Threads 演算法、AI 味、心理學知識整理自 AK-Threads-booster（AK SEO Labs，MIT）。**需要個人歷史數據的工作**（選題、預測 24 小時表現、發文後復盤、更新數據）不在這個 Skill，請用 AK-Threads-booster 本體

## 步驟 1｜寫作摘要

**目的：** 先想讀者看完要發生什麼，再回頭想他需要知道什麼，最後才動筆。從「我想說」換到「他想聽」。

**最少輸入：** 這篇寫給誰（具體情境）、一個真實素材、主要任務。

**動作：** 填 TA 情境、寫讀者一句話＋已知程度、選素材切角表達、定文案目的與主要任務、指定一度、寫核心主張與結尾。六格與各欄位的填法、範例看 `references/step1-brief.md`。

**輸出模板：**
```
## 寫作摘要｜〈主題〉
| 項目 | 內容 |
|---|---|
| TA 情境（六格挑一） | |
| 讀者 | 我寫給正在＿＿的人……（已知程度：＿＿） |
| 他想看的／他需要看的 | |
| 素材 | 生活／經歷／專業：〈一行〉（✅真實／📝示範／❓待補） |
| 切角／表達 | |
| 文案目的 | 想法：＿／決定：＿／動作：＿ |
| 主要任務 | |
| 指定一度 | |
| 信任三角（觀察） | |
| 核心主張 | |
| 結尾 | 判斷：＿ 或 下一步：＿ |
```

**檢核：** 讀者是具體情境（不是年齡層＋興趣）；素材是真的；任務、指定度各一個；主張一句話能重述。

## 步驟 2｜文案拆解：Hook＋內容＋CTA

**目的：** 一篇拆成三塊——Hook 讓對的人停下來，內容推進理解、兌現 Hook，CTA 完成任務。使用者貼一篇要「拆解」時，標出三塊各用了哪種寫法、哪裡斷掉。

**最少輸入：** 步驟 1 的摘要（缺就先補最少欄位）。

**動作：** 選主體骨架、用 4 欄填每個支持點、選 Hook 入口、選 CTA 型與大小。骨架庫、15 組邏輯工具、開頭心理機制、Hook／CTA 寫法與**範例庫**都在 `references/step2-structure.md`。同一篇選一個主骨架，工具名稱不放進成品。

**輸出模板：**
```
## 結構表｜〈主題〉
摘要：讀者＝｜素材＝｜表達＝｜任務＝｜指定度＝｜骨架＝
開場｜Hook：　脈絡：　預告：（短文可省）
主體
| 讀者的問題 | 關鍵訊息 | 素材 | 真實性 |
結尾｜收束：
```

**檢核：** 只讀關鍵訊息能串成一篇（沒有跳步、重複、離題）；開頭的問題正文有回答。

---

## 步驟 3｜AI 協助產出

**目的：** 讓 AI 出選項和初稿，作者做取捨——寫出「真的像作者」的稿。

**三種模式：** A 建風格卡／B 寫初稿／C 協作紀錄。沒有風格卡先問要不要建（或請作者貼 3–5 篇舊文）；作者不在就用平實具體的語氣寫，註明「未套用風格卡」。

**動作：** 依模式跑。每個模式的完整流程、欄位、K叔風格卡與 before/after 改稿範例在 `references/step3-draft.md`。核心：
- 寫初稿先分「固定與可變」，**核心主張、事實、服務範圍、指定度不能改**
- 缺的資料標【需補】，**不讓 AI 補**
- 給三個開頭、兩版初稿，附來源對照與取捨清單
- 像不像自己只有作者能判斷，列出原句請他確認

**輸出要點：** 素材盤點 → 3 個開頭（各註明要兌現什麼）→ 2 版初稿 → 來源對照 → 取捨清單。

---

## 步驟 4｜PDCA 優化：檢查、定稿與下一輪

**目的：** 發前抓問題、定稿，發後看訊號、規劃下一輪。一次只改一個主要因素。

**最少輸入：** 一篇草稿或已發文；有摘要更好，沒有就從草稿反推並標「反推」。

**動作：** 跑 P→D→C→A。C（檢查）跑三層：第一層判斷標準 → 第二層主張・證據・邏輯＋紅線＋AI 味 → 第三層交稿自查 10 項。完整三層、R1–R12 紅線表、AI 味檢測表、交稿自查清單在 `references/step4-pdca.md`。

**輸出模板：**
```
## PDCA 檢查｜〈首句〉
改善目標（P）：＿＿｜要看的訊號：＿＿（使用者沒給就問，或標「未設定」）
摘要：讀者＝｜素材＝｜任務＝｜指定度＝（沒給的標「反推」）
紅線警告（有命中才列，放最前面）
第一層｜項目｜判定 ✅/⚠️/❌｜問題句（引用原文）｜怎麼改
第二層｜同上
AI 味｜確定（引用原句→命中規則→修改方向）／可能／濃度
第三層｜交稿自查 10 項
最該先改的 3 件事（素材不實永遠排第一）
```
批次檢查另加：`| 篇名 | 素材 | 指定度 | 是否達成 | 信任角 |`

**檢查規則：** 先指出問題，不主動重寫全文；使用者說「幫我改」才給修改版，只動有問題的句子、保留原語氣；每個 ⚠️❌ 都引用原句並給具體改法，不寫「可以再加強」；證據不足時說要補什麼素材，不替作者編。
